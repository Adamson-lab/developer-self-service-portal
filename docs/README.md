# Documentation

| Folder | Audience | Contents |
|---|---|---|
| `architecture/` | Architects, engineers | Context, container, sequence, deployment and data-flow diagrams |
| `adr/` | Engineers, auditors | Architecture decision records: why each choice was made |
| `runbooks/` | On-call engineers | Step-by-step response for known failure modes |
| `security/` | CISO office, Security architecture | Threat model, control mapping, data handling |
| `executive/` | CIO, CISO, CFO, board committees | One-page briefing with decisions requested |

Diagrams are written in Mermaid so they render on GitHub and diff cleanly in review.
